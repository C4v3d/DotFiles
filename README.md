# DotFiles
This is a basic setup for different things I use on my machine. Standard black and white theme that will fits every laptop :).
This is not a static final form of my configuration !
![Screenshot of my fastfetch](./ff.png/?raw=true "Fastfetch")
## Stuff I use
short list of tools I use:
- sway (Wayland compositor).
- waybar (Customizable bar).
- kitty (terminal Emulator).
- rmpc (terminal based MPD client).
- wikiman (search engine for man pages).
- tealdeer (better implementation of tldr).
- nvim
- obsidian (note taking application).

These are the main tools I use everyday. I aim to keep this list simple and lightweight to be able to work on a variety of environment. In really there are many more tools that I use daily but these are the ones that followed me across machines.
## Philosophy
I think that having too many stuff on my computer directly impact my productivity. The goal is to get things done ! Notifications, easy access to source of distraction (games, social networks, etc...), bloatware, or unreliable operating system are either unnecessary or just unusable. Controlling my environment is great to test, break stuff, and learn. With local backups I can easily go back to a previous version of the system if something breaks. It also help understanding how things work, what piece of software is responsible for my internet connection ? How should I partition my disk ? Why is it not working and how can I fix it ?
### More
**sway** allows me to easily spread my workflow between multiple workspace, focus from one application to another without touching the mouse. Combined with **nvim**, I can be the most efficient in writing/debugging code. I can also consult man pages, wiki, or other documentation that I downloaded locally on my machine with **wikiman**, which allows me to work even when there is no Internet connection !

Being able to work on a pretty basic setup allows me to rely on old and cheap computer that I can easily repair. The word behind this setup might be *low-tech* -> doing the most with what I have.
